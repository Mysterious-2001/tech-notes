# 自信与主动性

## 核心判断

自信不是相信自己一定正确或一定会赢，而是相信：

> 我有价值，我可以学习，我能承担结果，我值得被认真对待。

它的实际用途是提供行动的起点，并让失败停留在事情层面，而不是升级为对整个人的否定。

## 为什么自信重要

- **敢于行动**：很多把握是在开始、反馈和调整中形成的，而不是开始前就存在。
- **承受失败**：把“这次方法不对”与“我这个人不行”分开，才能把失败转化为经验。
- **接受反馈**：稳定的自我价值感让人更敢提问、暴露不足和进入高水平环境。
- **建立平等关系**：不靠讨好换取认可，也不靠贬低别人证明自己。
- **保持主动性**：人生没有持续提供题目和标准答案的人，机会、关系和方向都需要主动争取。

## 自卑、傲慢与自信

| 状态 | 核心想法 |
| --- | --- |
| 自卑 | 我不行，我不值得。 |
| 傲慢 | 我一定比别人强。 |
| 自信 | 我有价值，也还有很多可以进步的地方。 |

自信与清醒并不冲突。真正的自信允许自己有缺点、犯错误，同时仍然愿意继续行动。

## 实践判断

遇到犹豫或失败时，问自己：

- 我是在评估真实风险，还是在回避被否定的感受？
- 这次结果说明了方法、能力阶段或环境的什么问题？
- 下一次最小可验证的行动是什么？
- 我是否把别人的评价误当成了自身价值的最终判决？
