# 职业目标

## 当前目标

当前阶段的职业目标是：

> 拥抱 AI，成为资深 Agent 开发工程师；在工程能力和业务判断成熟后，进一步晋升管理层；如果出现合适机会，也考虑创业。

这个目标方向是合理的，但不能只理解成“追 AI 风口”。真正值得押注的不是某个模型、框架或工具，而是：AI 正在改变软件生产方式，未来稀缺的人会是能定义问题、组织系统、驱动落地、承担结果的人。

## 第一性原理判断

职业选择的本质不是选择一个热门岗位，而是选择一种长期复利最高的能力组合。

这条路径的核心能力组合是：

1. Agent 工程能力：能把模型能力变成稳定、可评估、可维护的系统。
2. 产品和业务判断：知道什么问题值得用 AI 做，什么问题只是炫技。
3. 组织协作能力：能跨团队推进复杂事情，让别人愿意跟你一起做成事。
4. 商业敏感度：理解成本、交付、客户、分发和利润，而不是只理解技术实现。

如果只做第 1 点，天花板是高级工程师。如果能把 1-4 点连起来，才可能自然走向管理层或创业。

## 路径建议

### 近期：先成为强 Agent 工程师

未来 1-2 年，目标不要太早从技术逃向管理或创业。先把自己打成一个在 AI 工程里可靠的人。

关键动作：

- 深入理解 Agent 系统的基本构件：工具调用、记忆、上下文工程、规划、评估、权限、可观测性、成本控制。
- 积累真实项目经验，不只做 demo，要做可上线、可维护、能被评估的系统。
- 形成自己的 Agent 工程方法论，把经验沉淀成文档、模板、评估标准和复盘。
- 保持后端基本功，尤其是系统设计、数据流、稳定性、权限、安全和工程效率。

### 中期：从“会做”变成“能带方向”

当你能独立做成 Agent 项目后，下一步不是立刻转管理，而是成为能定义方向的人。

关键动作：

- 主动承担模糊问题，把业务需求拆成可验证的工程方案。
- 练习写方案、做复盘、做技术评审，而不是只交付代码。
- 建立跨团队信任，让产品、业务、算法、后端、前端都觉得你能把事情推进下去。
- 关注投入产出比：节省了多少人力、提高了多少效率、带来了多少收入或成本下降。

### 长期：管理和创业是结果，不是逃生通道

管理层和创业都不是“技术之后的下一站”，而是当你能持续组织资源、承担更大不确定性时自然出现的选择。

判断是否适合管理：

- 你是否愿意通过成就别人来放大结果。
- 你是否能处理目标冲突、人员差异和长期反馈延迟。
- 你是否能从“我把事情做对”切换到“我让团队持续做对”。

判断是否适合创业：

- 你是否发现了真实、高频、强痛点的问题。
- 你是否能接触到目标客户，而不是只想象需求。
- 你是否能接受长期不确定性、现金流压力和非技术问题。
- 你是否有一个小切口，可以用低成本验证，而不是一上来赌人生。

## 当前策略

现在最合理的策略是：

> 以 Agent 工程为主线，以管理能力和商业判断为副线，先获得选择权，再决定是否转管理或创业。

不要过早把自己绑定为“我要当管理者”或“我要创业”。更好的表述是：

> 我要成为能用 AI 做成复杂事情的人，并逐步获得技术专家、管理者和创业者三条路径的选择权。

这样目标足够硬，但不会把路径锁死。

## 需要持续追问的问题

- 我做的 AI 项目，是真解决问题，还是只是技术展示？
- 我有没有形成别人可以复用的方法论？
- 我是否能把模糊需求变成清晰边界和可验证结果？
- 我是否能影响别人，而不只是在自己的任务里表现好？
- 如果创业，我能服务谁？他们为什么现在就需要我？
