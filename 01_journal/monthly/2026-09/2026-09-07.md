```
AgentRequestContext
  ├─ skill_planner      → 一个 UUID
  ├─ tool_planner       → 一个 UUID，多轮复用
  ├─ context_extractor  → 一个 UUID，多轮复用
  └─ reflection         → 一个 UUID
```
fork 时会创建新的 `AgentRequestContext`，继承：

- `request_id`
- `conversation_id`
- 必要的业务上下文

但不会继承 `model_gateway_session_ids`，所以每个 fork 分支会生成自己的 stage session

父分支 tool_planner      → session A
父分支 context_extractor → session B

fork branch 0 tool       → session C
fork branch 0 context    → session D

fork branch 1 tool       → session E
fork branch 1 context    → session F


分支结束回到父流程后，父流程继续使用 A/B
