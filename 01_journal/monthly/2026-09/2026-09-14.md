- `contracts.py`：Planner 与 Runtime 的数据契约，两者保持独立。
- `catalog.py`：唯一注册入口，负责名称唯一性、稳定顺序和定义查询。
- `executor.py`：Runtime Tool 的串并行执行、结果记录和摘要。
- `observation.py`：Tool observation 去重 key。
- `planning/`：所有 Tool 共用的注册、校验、编译框架，不包含具体 Tool 业务。
- `protocols/concise.py`：原样承接 concise/lite 的 JSON 解析和适配。
- `_capabilities/`：具体能力实现，仅允许 `catalog.py` 引用。

能力归属：

- `execute_afs_commands.py`：Planner Tool `execute_afs_commands` 与 Runtime Tool `afs_command`。
- `load_reference.py`：同名 Planner/Runtime Tool。
- `fork_files.py`、`fork_references.py`：各自独立的 schema、availability 和 compiler。
- `finish_skill.py`：结束当前 Skill 的控制型 Planner Tool。
